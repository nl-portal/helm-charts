# nl-portal-backend 3.2.1

App version: NL Portal `3.1.2`. Supports NL Portal 3.1.x.

## Changes

- `appVersion: 3.1.2`.
- NL Portal 3.1.2 fixes [GHSA-6rxj-f2rp-7mp3](https://github.com/nl-portal/nl-portal/security/advisories/GHSA-6rxj-f2rp-7mp3): the return URL of a payment is only used when it has the same origin as the URL in the payment profile. With `payment.direct` or `payment.ogone` enabled, set an absolute URL in the payment profile: without it, users do not return to the portal after paying.

## Migration

Only relevant with `settings.services.payment.direct.enabled` or `settings.services.payment.ogone.enabled`. Set the payment profile URLs to the portal's URL, with the origin exactly as the browser shows it: lowercase scheme and host, no default port (`:443` or `:80`). Values set through `extraEnvVars` work too.

```yaml
# Direct payment
# Before
settings:
  services:
    payment:
      direct:
        enabled: true
        properties:
          configurations:
            belastingzaken:
              pspId: TAX

# After
settings:
  services:
    payment:
      direct:
        enabled: true
        properties:
          configurations:
            belastingzaken:
              pspId: TAX
              returnUrl: https://portal.example.nl
```

```yaml
# Ogone payment
# Before
settings:
  services:
    payment:
      ogone:
        enabled: true
        properties:
          configurations:
            belastingzaken:
              pspId: TAX

# After
settings:
  services:
    payment:
      ogone:
        enabled: true
        properties:
          configurations:
            belastingzaken:
              pspId: TAX
              successUrl: https://portal.example.nl
              failureUrl: https://portal.example.nl
```
