# nl-portal-configpanel-backend 3.0.0

App version: Configuration Panel `2.0.0`. Supports Configuration Panel 2.0.x.

## Breaking changes

- Chart version jumps from 1.x to 3.0.0 (aligns chart family with nl-portal major version)
- `image.tag` default changed from `"latest"` to `""` (uses appVersion)
- HPA API updated from `autoscaling/v2beta1` to `autoscaling/v2`
- Minimum Kubernetes version: 1.23 (`kubeVersion: ">=1.23.0"`)
- `secretEnvVars` pattern now coexists with new `existingSecret` option; both disable chart-managed Secret
- Fixed `settings.app.configServerToken` → use `settings.app.serverToken`
- Secret now uses `stringData` (was broken `data` without base64 encoding)

## New features

- HPA now supports memory metric via `autoscaling.targetMemoryUtilizationPercentage`
- Probes use `/management/health/*` endpoints

## Migration

```yaml
# existingSecret option added
# Before (1.x) - only secretEnvVars for external secrets
secretEnvVars:
  - name: DATABASE_PASSWORD
    valueFrom:
      secretKeyRef:
        name: my-secret
        key: password

# After (3.x) - can also use existingSecret for whole secret
existingSecret: my-secret
# Or keep using secretEnvVars for partial secret injection
```
