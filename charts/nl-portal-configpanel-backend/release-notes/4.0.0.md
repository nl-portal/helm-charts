# nl-portal-configpanel-backend 4.0.0

App version: Configuration Panel `3.0.0`. Supports Configuration Panel 3.0.x.

Upgrading? See [Migration](4.0.0-migration.md).

## New features

- **Admin roles**\
  `settings.auth.{authorities,authoritiesClaimExpression}` set which roles may use the panel and where they are read from the token. Empty keeps the panel's defaults (`ROLE_CONFIG_PANEL_ADMIN`, `['realm_access']['roles']`).

- **Allowed property keys**\
  `settings.app.security.allowedKeyPrefixes` sets the key prefixes the panel reads, writes, deletes and serves. Default `null` (the panel's default prefixes); an empty value fails templating, because the panel would read it as "allow every key".

- **Notify client**\
  `settings.app.notify.client.{tokenUri,clientId,clientSecret,scope}` configure the client the panel uses to get a token for notifying NL Portal. `settings.app.notify.{connectTimeout,readTimeout}` limit how long a notify can take.

- **Encryption**\
  `settings.app.encryption.{enabled,key}` turn encryption of stored values on or off and set the key.

## Breaking changes

- **Non-root image**\
  The image runs as non-root (uid 1001). Check your `securityContext` and volume permissions.

- **No debug port**\
  Port 8000 (debug) is gone. Use `JAVA_TOOL_OPTIONS` to debug.

- **Admin role required**\
  Panel users need the role `ROLE_CONFIG_PANEL_ADMIN`, or set `settings.auth.authorities`.

- **Only NL Portal configuration keys are managed**\
  Only property keys under `nl-portal.config.` and `nl-portal.frontend.` are read, written, deleted and served, unless you set `settings.app.security.allowedKeyPrefixes`. Retired keys can always be deleted.

- **Notify needs a client**\
  With `settings.app.notifyEnabled`, `settings.app.notify.client.tokenUri`, `clientId` and `clientSecret` are required. Templating fails without them (the secret only when the chart renders its own Secret).

- **Encryption key required**\
  With `settings.app.encryption.enabled` (default `true`), `settings.app.encryption.key` is required. Templating fails without it when the chart renders its own Secret. NL Portal needs the same key.

- **Open Product settings must be entered again**\
  Enter the Open Product settings again in the panel.

- **Panel settings override the portal's environment variables**\
  Settings saved in the panel override the portal's environment variables, including the new portal interface and Verificatie sections.
