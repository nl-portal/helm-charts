# nl-portal-configpanel-frontend 4.0.0

App version: Configuration Panel `3.0.0`. Supports Configuration Panel 3.0.x.

Upgrading? See [Migration](4.0.0-migration.md).

## New features

- **New example application name**\
  The panel's examples use the application name `nl-portal-app` (was `nl-portal-backend-libraries`). The chart default stays empty.

## Breaking changes

- **Non-root image**\
  The image runs as non-root (uid 101).

- **No read-only root filesystem**\
  The frontend writes `config.js` on start, so it does not support `readOnlyRootFilesystem`.
