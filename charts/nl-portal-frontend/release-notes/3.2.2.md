# nl-portal-frontend 3.2.2

App version: NL Portal `3.1.3`. Supports NL Portal 3.1.x.

## Changes

- No changes to the chart. `appVersion: 3.1.3`.
- Skips 3.2.0 and 3.2.1 to line up with nl-portal-backend again. From this version on, nl-portal-backend and nl-portal-frontend share chart versions.

## Deprecations

- `settings.features.useLegacyOgonePayment`. NL Portal no longer supports Ogone e-Commerce and removes it in 4.0.0, together with `USE_LEGACY_OGONE_PAYMENT`.
