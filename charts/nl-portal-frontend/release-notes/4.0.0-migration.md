# nl-portal-frontend 4.0.0 migration

Depends on: nl-portal-backend 4.0.0. Upgrade this chart right after it: the 4.0.0 frontend gets its features from the 4.0.0 backend.

1. **Move the frontend values**\
   Move them to nl-portal-backend's `settings.frontend`. See the nl-portal-backend 4.0.0 migration notes for the mapping.

2. **Update the values**\
   Set `image.repository` to `ghcr.io/nl-portal/nl-portal-frontend`, or remove your override. Remove `settings.features`, `settings.themeClass`, `settings.overview`, `settings.account` and `settings.brpUrls`.

3. **Upgrade**\
   Log in and check that the features you enabled show.
