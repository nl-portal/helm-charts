# nl-portal-frontend 4.0.0

App version: NL Portal `4.0.0`. Supports NL Portal 4.0.x.

Upgrading? See [Migration](4.0.0-migration.md).

## Breaking changes

- **New image name**\
  The default `image.repository` is now `ghcr.io/nl-portal/nl-portal-frontend`. NL Portal 4.0.0 dropped the `-app` infix from its image names, and the old `nl-portal-app-frontend` image has been archived. While `image.repository` still ends in the old name, `helm install` / `helm upgrade` print a warning with the chart notes.

- **Feature values moved to nl-portal-backend**\
  The chart renders only the OIDC settings and `backendUrl`. `settings.features`, `settings.themeClass`, `settings.overview`, `settings.account` and `settings.brpUrls` moved to `settings.frontend` in nl-portal-backend. Templating fails while any of them is set.
